# Recruitment Module - Designer Documentation

## Overview

UI/UX specifications, visual design patterns, and user interface guidelines for the complete recruitment pipeline from job requisitions through candidate selection and employee creation.

---

## Design System

### Color Palette

**Status Colors**:
```
Open/Pending:     #FFA00A (Orange)
Approved:         #2490EF (Blue)
Accepted:         #98D85B (Green)
Rejected:         #F56B6B (Red)
On Hold:          #FFD66B (Yellow)
Cancelled:        #9B9B9B (Gray)
Filled:           #98D85B (Green)
```

**Applicant Status Colors**:
```
Open:             #FFA00A (Orange)
Replied:          #2490EF (Blue)
Hold:             #FFD66B (Yellow)
Accepted:         #98D85B (Green)
Rejected:         #F56B6B (Red)
```

**Interview Status Colors**:
```
Pending:          #FFA00A (Orange)
Cleared:          #98D85B (Green)
Rejected:         #F56B6B (Red)
```

### Typography

**Form Titles**: 18px, Semi-bold, #2C3E50
**Section Headers**: 14px, Semi-bold, #4A5568
**Field Labels**: 12px, Regular, #718096
**Field Values**: 14px, Regular, #2D3748
**Helper Text**: 11px, Regular, #A0AEC0

### Spacing

**Section Gaps**: 24px
**Field Gaps**: 16px
**Column Gaps**: 20px
**Card Padding**: 20px
**Button Padding**: 8px 16px

- **Minimum Touch Target**: 44px × 44px for all interactive elements

- **Focus Indicators**: 2px blue outline on keyboard focus
- **Screen Reader Labels**: All form fields have aria-label attributes
- **Keyboard Navigation**: Full support for Tab, Enter, Escape keys
- **Error Announcements**: ARIA live regions for validation messages
